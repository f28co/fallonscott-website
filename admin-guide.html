— 02 / CopyEditing copy

Where to find sections inside each file

Each section is wrapped in HTML comments like this:

<!-- HERO -->
<section ...>...</section>

<!-- THE JOURNEY -->
<section ...>...</section>

Use Ctrl+F / Cmd+F in your editor and search for the comment to jump to a section.

Common edits

Change a headline

Look for <h1>, <h2>, or <h3> tags. Change the text between the opening and closing tag.

<h2>You don't need a bigger team. You need <em>a system.</em></h2>
                                            ^^^^^^^^^^^^^^^^^^^
                                            italics — keep the <em> tags
                                            around words you want italicized

Change body copy

Look for <p> tags.

Change a button label

Look for <a ...>...</a> and change the text between the tags. Leave class= and href= alone.

<a href="#contact" class="btn">Book a Discovery Call <span class="arrow">→</span></a>
                                ^^^^^^^^^^^^^^^^^^^^^
                                edit this text only

Edit the FAQ

Scroll to the <!-- FAQ --> section. Each Q&A is one block:

<div class="faq-item">
  <div class="faq-q"><span>QUESTION GOES HERE</span><span class="ico"></span></div>
  <div class="faq-a"><div class="faq-a-inner"><p>ANSWER GOES HERE</p></div></div>
</div>

Copy a whole block to add a new FAQ. Delete a whole block to remove one.

Special syntax

  • <em>...</em> = italics
  • <strong>...</strong> = bold
  • <br> = line break
  • &amp; = the character &
  • &mdash; or — = em dash

— 04 / BookingDiscovery Call links — IMPORTANT

Right now, every "Book a Discovery Call" button links to #contact — which scrolls to the bottom of the homepage. This is a placeholder. When you have your real booking link (Calendly, TidyCal, SavvyCal, Cal.com, whatever), replace it everywhere.

Find every booking link

Search across all files for: href="#contact"

You'll find it in:

  • index.html — top nav button, hero CTA, multiple CTAs throughout, footer
  • about.html — top nav button, hero CTA, multiple CTAs, footer
  • sop-suite.html — "Done with you" path CTA
  • speaking.html — top nav button, footer

Replace with your real link

Change every href="#contact" to href="YOUR-BOOKING-URL" and add target="_blank" rel="noopener" so it opens in a new tab.

<!-- Before -->
<a href="#contact" class="btn">Book a Discovery Call</a>

<!-- After -->
<a href="https://calendly.com/fallonscott/discovery"
   target="_blank" rel="noopener" class="btn">Book a Discovery Call</a>

Tip — use Find & Replace All

Most editors have Find & Replace in All Files (VS Code: Ctrl+Shift+H / Cmd+Shift+H). Set find to href="#contact" and replace with href="YOUR-LINK" target="_blank" rel="noopener". One operation, done.

Email contact & the contact form

Search for mailto: to find email contact links. There's also a contact form section on the homepage (search <!-- CONTACT -->) — it's currently visual-only; you'll need to wire it up to a form service (Formspree, Netlify Forms) before launch, OR delete it and rely on email + booking link.

— 06 / PhotosSwapping or adding images

Swap an existing image

  1. Save the new photo as .jpg (NOT .png) at around 1600px wide max, quality ~80%. Under 400KB if possible.
  2. Drop it into site-a/assets/.
  3. In your HTML, find the existing <img src="assets/old-name.jpg" ...> and change old-name.jpg to your new filename.

Add a new image somewhere

<img src="assets/your-new-image.jpg"
     alt="Describe the photo for accessibility and SEO"
     loading="lazy" />

loading="lazy" keeps the page fast. alt text is required — describe the image.

Sizing photos for the web (free tools)

  • Squoosh.app — drop in, resize, export — best quality-per-byte.
  • TinyPNG.com — also handles JPGs despite the name.

Rule of thumb:

  • Hero images: 1600px wide, ~250KB
  • Section images: 1200px wide, ~150KB
  • Thumbnails: 600px wide, ~80KB

Updating social-share images (Open Graph)

When someone shares your site on LinkedIn / Facebook / iMessage, the image they see is from assets/og-cover.jpg (and the per-page OG images). To update:

  1. Make a 1200×630px image (NOT square — landscape).
  2. Save as assets/og-cover.jpg (overwrite the existing one).
  3. Test: paste your URL into opengraph.xyz to preview.

— 07 / BannerEditing the top promo banner

Lives at the very top of index.html, about.html, and speaking.html. Search for id="sopBanner".

Hide the banner entirely

Comment out the whole <div id="sopBanner">...</div> block by wrapping it in <!-- ... -->.

Change the link target

Change href="sop-suite.html" to wherever you want the banner to send people.

Reset banner for users who dismissed it

If you change the banner copy, users who already dismissed the old version won't see the new one (it's cached in their browser). To force-show it again, change localStorage.setItem('sopBannerHidden','1') to use a new key like 'sopBannerHidden_v2' (and update the matching getItem check).

— 08 / SEOSEO updates

Once you have your final domain

Search for fallonscott.com across all files and replace with your actual domain. Specifically:

  • Every <link rel="canonical"> tag
  • Every <meta property="og:url"> tag
  • sitemap.xml (every <loc> line)
  • llms.txt (every URL)
  • Schema JSON-LD blocks ("url":"..." and "image":"...")
  • robots.txt (if it lists a sitemap URL)

Per-page SEO knobs

In each HTML file, the top of the <head> has:

  • <title> — what shows in the browser tab and Google results (keep under 60 chars)
  • <meta name="description"> — Google's preview snippet (keep under 160 chars)
  • <meta name="keywords"> — minor SEO weight, keep relevant
  • <meta property="og:title"> and og:description — what shows on social shares

Submit to Google

After deploying, go to Google Search Console, verify your domain, and submit https://YOUR-DOMAIN/sitemap.xml. Google starts indexing within days.

— 09 / DeployDeploying to Netlify

First-time deploy

  1. Sign up at netlify.com — free.
  2. Click Add new site → Deploy manually.
  3. Drag the entire site-a/ folder onto the upload area.
  4. Done. Netlify gives you a URL like https://random-name-12345.netlify.app.

Updating after edits

Easiest method: drag the folder again onto your Netlify site dashboard ("Deploys" tab → "Drag and drop your site folder here"). It replaces the old version.

Better long-term: connect to GitHub

If you put site-a/ into a GitHub repo, Netlify will auto-deploy every time you push a change. Worth setting up once you're past the soft-launch phase.

Pointing a custom domain

  1. In Netlify dashboard: Domain management → Add a custom domain
  2. Enter your domain.
  3. Netlify shows you DNS records to set at your registrar.
  4. At GoDaddy / Namecheap / wherever you bought the domain, paste those records into DNS settings.
  5. Wait ~30 mins for propagation. SSL/HTTPS auto-enables.

— 10 / Domainfallonrice vs fallonscott

You currently own fallonrice.com. The site is branded as Fallon Scott.

Option A — Keep fallonrice.com

  • No purchase needed.
  • Visitors who type "fallonrice.com" land on the site.
  • The brand on the site says "Fallon Scott." That's fine; the URL is just a handle.

Option B — Buy fallonscott.com

  • ~$12/year at any registrar.
  • Set fallonscott.com as primary in Netlify.
  • Set fallonrice.com to redirect to fallonscott.com (Netlify makes this one click).
Recommendation: Option B if available. The URL matching the brand is a small but real trust signal.

— 11 / TroubleshootingCommon gotchas

"I changed something but I don't see it on the site"

  • You're looking at a cached version. Hard-refresh: Ctrl+Shift+R (Windows) / Cmd+Shift+R (Mac).
  • If you deployed to Netlify, give it 30 seconds to publish.

"I broke something and the page looks weird"

  • HTML is unforgiving. A missing > or stray quote can shatter the layout.
  • Open the page in your browser, right-click → "View Page Source" to see if HTML rendered correctly.
  • Always keep a backup — copy the file to index-backup.html before big edits.

"The promo banner won't go away even after I edited it"

  • Browsers cache localStorage. Open dev tools (F12) → Application → Local Storage → delete sopBannerHidden.
  • Or use a different browser to test.

"Photos look stretched or pixelated"

  • Photo's aspect ratio doesn't match the container. Either crop the photo to match, or remove the aspect-ratio CSS rule on that section.

"Links to other pages are broken"

  • Check the link spelling matches the filename exactly. Case matters: About.html ≠ about.html.
  • All inter-page links use lowercase: index.html, about.html, sop-suite.html, speaking.html.
